# 🎨 Box Shadow Generator

A simple and interactive **Box Shadow Generator** built using HTML, CSS, and JavaScript.

This project allows users to create and customize CSS box shadows by adjusting different shadow properties and instantly previewing the result.

## 🚀 Features

* 🎨 Generate custom CSS box shadows
* ↔️ Adjust horizontal shadow offset
* ↕️ Adjust vertical shadow offset
* 🌫️ Adjust blur radius
* 📏 Adjust spread radius
* 🎨 Change shadow color
* 🔄 Adjust shadow properties in real time
* 📋 Copy generated CSS code
* 👀 Live preview of the box shadow
* 📱 Responsive design
* ✨ Simple and user-friendly interface

## ⚙️ How It Works

The Box Shadow Generator uses JavaScript to update CSS box-shadow properties based on the values selected by the user.

### Shadow Generation Process

1. User adjusts the shadow properties.
2. JavaScript reads the selected values.
3. The `box-shadow` CSS property is generated dynamically.
4. The shadow is displayed on the preview box.
5. The generated CSS code is shown to the user.
6. The user can copy the CSS code for use in other projects.

### CSS Box Shadow Syntax

```css
box-shadow: horizontal-offset vertical-offset blur-radius spread-radius color;
```

Example:

```css
box-shadow: 10px 10px 20px 5px #888888;
```
